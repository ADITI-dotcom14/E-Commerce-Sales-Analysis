# E-Commerce Sales Performance & Revenue Leakage Analysis

## Project Overview
An end-to-end Python data analysis project exploring e-commerce revenue drivers, fulfillment bottlenecks, and discount elasticity. This project takes raw, messy sales data and transforms it into actionable business insights.

## Tech Stack
* **Language:** Python
* **Libraries:** Pandas (Data Cleaning & Wrangling), Matplotlib & Seaborn (Visualization)
* **Environment:** Jupyter Notebook

## Key Business Insights Discovered
1. **The Revenue Driver:** The South region leads total volume, with *Running Shoes* and *Backpacks* driving the highest net revenue across all categories.
2. **The Logistics Risk:** Despite lower overall volume, the East region has a critical 25% fulfillment failure rate (cancelled/returned orders), requiring immediate logistical review.
3. **The Margin Leak:** Heavily discounting low-ticket items (e.g., USB Chargers at 11.5% off) fails to drive significant sales volume and primarily dilutes net profit margins.
